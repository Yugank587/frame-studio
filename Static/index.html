WELCOME TO FRAME STUDIO

Sort, edit and export your photos in one calm workspace.

Frame Studio groups visually similar images, gives you precise local editing tools, and keeps the original files unchanged until you choose an action.

THE QUICK TOUR

Four steps from folder to finished images

Everything runs on this computer.

1. Add your photos

Choose individual images or add a folder. In Library, select one or more images to download or delete them individually. Originals are not recompressed.

2. Review duplicates

Open Duplicates to review grouped lookalikes. Select extras only after checking them; deletion is permanent and always asks for confirmation.

3. Edit side by side

Select a thumbnail to edit it. Crop, resize, tune brightness, contrast, color temperature and saturation, sharpen or blur, or apply a filter. All adjustments are processed locally.

4. Download or export

Select only the images you want to download as a lossless ZIP, download all originals, or export the images shown as a PDF.

Editing and comparing

  • New uploads open in Adjust automatically. Changes appear in the right-hand preview as you move the controls; Apply edits prepares the full-size download.
  • Choose Freeform, 1:1, 16:9, 3:4, or a custom crop ratio. Enter exact output dimensions when needed.
  • Adjust brightness, contrast, saturation, color temperature, sharpness and blur; try Warm, Cool, Vivid, Vintage, Black & white, Sepia or Soft focus.
  • In Library, choose Select to download or Delete images, then click one or more individual photos. Deletion asks for confirmation.
  • Choose PNG or TIFF for lossless edits. JPEG and WebP are compressed formats; the original stays untouched.

Privacy, PDFs and account recovery

  • Frame Studio listens only on this computer. Your library stays in the local Uploads folder.
  • PDF-to-Word and Word-to-PDF tools run locally. Microsoft Word is required for Word-to-PDF conversion.
  • Set up email recovery in Account settings using your SMTP provider and an app password; recovery email must be verified.

Make a PDF editable

PDF → Word → PDF
Convert a PDF to DOCX, edit the result in Word, then convert the edited file back to PDF.

Word-to-PDF conversion uses Microsoft Word installed on this computer. PDF-to-DOCX conversion runs locally. For Google Docs, download the document as DOCX first. Complex layouts may need cleanup, and scanned PDFs need OCR before their text can be edited.

To make a PDF from your images, return to Library or Duplicates and use Export PDF. The export follows the images currently shown.
